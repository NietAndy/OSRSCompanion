# 🛠️ Hotfix: melden kan weer

Beste avonturiers,

Dit is een hotfix. In de vorige versie kwam een melding via Meld een probleem niet aan. Dat is hersteld: je melding komt nu in ons kanaal #bugs, en wij maken er een issue van. Je hoort in de thread onder je melding wat er gebeurt. Verder is er niets veranderd.
