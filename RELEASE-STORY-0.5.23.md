# 📈 Hoe snel ga jij?

Beste avonturiers,

Haal je levels op bij Levels en account, en de app onthoudt hoeveel xp je had. Haal je ze later nog eens op, dan zie je per skill hoeveel xp je erbij hebt, hoeveel per dag, en over hoeveel dagen je level 99 haalt als je zo doorgaat. Er is ook een grafiek per skill.

Alles blijft op je eigen pc. Hoe vaker je ophaalt, hoe beter het tempo klopt.
